# 架構

這份文件描述現行產品。行為以這裡為準。

## 產品

香港智慧城市地圖是一個靜態網頁。底圖是 [OpenFreeMap Liberty](https://tiles.openfreemap.org/styles/liberty)。圖上有 10 條港鐵重鐵綫、98 個車站，以及 1013 個運輸署交通快拍點。

使用者可以：

- 搜尋車站或快拍點，並用鍵盤選取
- 看正在看的那個車站的到站班次
- 看正在看的那個快拍點的最新照片
- 開關港鐵網絡
- 在全市視角打開快拍點，或放大到街道才看到它們
- 把地圖傾斜，看立體建築物

輕鐵 68 個站和高鐵西九龍站沒有放進這份到站資料，地圖上不畫。

## 執行形態

瀏覽器裡的 React 單頁應用，沒有自己的後端，也沒有帳戶或資料庫。到站班次和快拍照片由瀏覽器直接向政府網站讀取，不經這個專案的伺服器轉送。

車站座標、路綫和快拍點清單在建立資料時寫進 `src/data/`。頁面不會每次向地政總署要座標。

現行正式版由 Cursor 託管。每一次發佈記在 [CHANGELOG.md](CHANGELOG.md)。公開程式在 <https://github.com/ryansham/hkmap-traffic>。

`wrangler.jsonc` 只描述一份可選的 Cloudflare 靜態輸出。它不是現行正式版的發佈方式。

## 建立時的資料

`npm run data` 執行 `scripts/build-data.mjs`，讀這些資料：

- 路綫與站序：<https://opendata.mtr.com.hk/data/mtr_lines_and_stations.csv>
- 車站範圍：地政總署 CSDI `mtr_venue_polygon`。座標用範圍方框的中心。
- 快拍位置：<https://static.data.gov.hk/td/traffic-snapshot-images/code/Traffic_Camera_Locations_Tc.csv>
- 路軌形狀：OpenStreetMap 裡網絡為港鐵的地鐵路綫。只取行走中的軌道，不取月台。每段車站之間沿這些軌道找最短路徑，再把 8 米以內的多餘轉折收掉。關係編號存在 `scripts/mtr-route-ids.json`，Overpass 可用時會更新。

中文站名的 `茘` / `荔`、`啓` / `啟` 會摺成後者。馬場站不在港鐵站序裡，用地政總署範圍補上，英文名 Racecourse。東鐵主綫不經過馬場；馬場支綫是沙田、馬場、大學。將軍澳綫另有康城支綫。路軌是曲線，不是車站之間的直線。車站圓點仍放在地政總署範圍的中心，所以大型車站的圓點可以離路軌幾十米。

快拍點 `AID10120` 的官方座標離開深圳灣公路大橋約 7 公里。建立時改放在大橋北端 `113.9555, 22.47685`。

## 打開頁面之後的資料

到站班次只查正在看的車站，約每 20 秒更新一次：

`https://rt.data.gov.hk/v1/transport/mtr/getSchedule.php?line={綫}&sta={站}&lang=TC`

`src/lib/schedule.ts` 把回應分成幾種畫面：

- 有班次
- 成功但沒有班次
- 港鐵標記服務延誤
- 總站的另一個方向寫「這個方向沒有列車。」
- 取不到資料，包括 HTTP 429 和 500

快拍照片在點開該點時才下載：`https://tdcctv.data.one.gov.hk/{key}.JPG`。切換到另一個快拍點會清掉上一張的錯誤。

## 地圖

MapLibre 使用上面的 Liberty 樣式。Worker 在 `src/main.tsx` 用 `setWorkerUrl` 設定。

初始視野蓋住香港。縮放約 10.4，最小 9，最大 18，最大俯仰 70 度。

港鐵每條綫沿著真實路軌畫成曲線，有白邊，並且按綫偏移，重疊的路段仍然分得開。車站是白點，選中的站會放大。快拍點是深色圓點。

快拍點的出現規則在 `cameraZoomBounds`：

- 「交通快拍」沒有按下時，圓點從縮放 13 才出現。這是街道尺度。全市視角只有港鐵。
- 「交通快拍」按下時，圓點從縮放 0 就出現，全市都看得到。
- 快拍點的文字標籤始終從縮放 13.4 才出現。

導航控制有羅盤，並顯示俯仰。3D 按鈕把俯仰設為 60 度；方向若是正北，就轉到 -24 度，否則保留目前方向；縮放至少 15.7。俯仰回到接近 0 度時，按鈕自己復位。動畫途中再按之前，會先停下目前的相機動畫。

桌面打開資料面板時，地圖右側留 400 像素。手機留出抽屜的實際高度，選中的地點不會藏在抽屜下面。

## 介面

頁首在寬螢幕是一行：標題、關於、搜尋、兩個開關。窄螢幕把搜尋和兩個開關各自放成一行，避免文字被切掉。98 個站、1013 個快拍點、不包括輕鐵和高鐵，以及資料出處，都在「關於」裡。Escape 先關關於，再清搜尋文字，再關資料面板。

搜尋同時比對車站的中文名、英文名、代號，以及快拍點的地點、地區、區域、代號。最多 8 筆。同一個匹配程度時車站排在快拍點前面。上下鍵移動，Enter 打開。中文輸入法組字時，Enter 不會提前選取。

三個別名只在整段搜尋文字完全相等時使用：

| 搜尋 | 找到的快拍點 |
| --- | --- |
| 紅隧 | 描述含「海底隧道」，但不含「東區海底隧道」或「西區海底隧道」 |
| 東隧 | 描述含「東區海底隧道」 |
| 西隧 | 描述含「西區海底隧道」 |

從搜尋打開一個地點時，地圖會飛過去，縮放至少 14.5，所以快拍點在街道尺度看得到。

資料面板在桌面貼在右側，用「關閉」按鈕或 Escape 或點空白地圖關掉。

在 760 像素或更窄的畫面，資料面板是底部抽屜：

- 先露出名稱。車站再露出最近的兩班車；其餘方向在抽屜裡說明還有幾多個。快拍點先露出照片時間，照片本身在拉起之後。
- 點一下抽屜把手會展開或收起。向上拉展開。向下拉時，展開中的抽屜先收起，已經收起的抽屜會關閉。
- 這個寬度不再顯示右上角的「關閉」。

## 不在這個產品裡

- 輕鐵和高鐵西九龍的到站班次
- 帳戶、資料庫，或一個替瀏覽器轉送政府資料的後端
- 用 `wrangler.jsonc` 發佈現行正式版
