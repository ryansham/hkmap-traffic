# 發佈紀錄

這份文件是每一次正式版發佈的唯一紀錄。新的一則寫在最上面。寫下這一則之後才發佈；引入這一則的提交，就是該次發佈的程式。

每一則要寫明：日期（香港時間）、發到哪裡、使用者看得到的改變。網址或上線結果若和事先寫的不同，在同一則補上，不另開紀錄。

2026-11-21 首次發佈和 CodeRabbit 再發佈這兩則，是這份紀錄建立之前已經上線的版本，由當時代碼提交還原。

## 2026-11-21 — 在路軌上顯示估算中的列車

- 目標：Cursor 上的 hkmap-traffic，<https://hkmap-traffic.apps.grok.bot>
- 打開車站後，每個方向的下一班車會沿路軌移動。位置用該站已載入的到站時間和路軌長度估算。
- 不會為了畫列車再查其他車站。分頁隱藏時暫停到站查詢。
