# 文件

這裡是這個專案的唯一依據。產品做什麼、程式怎麼拆、每一次正式版改了什麼，以這三份文件為準。

| 文件 | 負責的事 |
| --- | --- |
| [ARCHITECTURE.md](ARCHITECTURE.md) | 產品範圍、資料從哪裡來、地圖和介面怎麼運作 |
| [CHANGELOG.md](CHANGELOG.md) | 每一次發佈或部署 |

根目錄的 `README.md` 只說明怎麼在本機跑起來。它不記載行為細節，也不記載哪一次發佈上了什麼。

## 什麼時候改

- 使用者看得到的行為變了，或資料流、圖層、外部來源變了：在同一次改動更新 `ARCHITECTURE.md`。
- 每一次把正式版發出去之前：在 `CHANGELOG.md` 最上面加一則。沒有這則，那一次發佈就不算有紀錄。
- 發佈之後如果網址或上線結果和那一則不同，立刻補上實際結果，不要另開一份紀錄。

聊天紀錄、程式註解和舊的說明如果和這裡不一致，以這裡為準，並在同一次改動把錯的地方改掉。
